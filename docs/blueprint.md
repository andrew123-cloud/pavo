# **App Name**: Pavo Suite

## Core Features:

- Unified Branding: Consistent design language across Pavo Interiors (pavointeriors.com), Pavo Decors (pavodecors.com), and Pavo Homes (pavohomes.com).
- Cross-Site Navigation: Top navigation bar with quick links to switch between the three Pavo sites.
- Responsive Layout: Fully responsive design adapting to desktop, tablet, and mobile devices.
- Performance Optimization: Optimized website speed and SEO-friendly structure to improve search engine rankings.
- Newsletter Sign-up: Integrated form to subscribe to an email newsletter on each of the three sites.
- Personalized Recommendations: AI tool that learns user preferences across all three Pavo sites to provide personalized interior design tips and product recommendations, all in accordance with applicable laws.

## Style Guidelines:

- Primary color: Muted gold (#CBB386) to evoke sophistication and warmth, reflecting premium design. Gold often represents luxury, quality, and elegance.
- Background color: Light beige (#F5F5DC), desaturated and bright. Provides a soft, neutral backdrop to ensure content stands out.
- Accent color: Terracotta (#E2725B) adds a pop of earthy vibrancy that remains in harmony with the muted primary. It evokes warmth and rustic charm.
- Body and headline font: 'Alegreya', a serif font suitable for both headlines and body.
- Simple, line-based icons to maintain a clean and modern aesthetic.
- Clean, grid-based layout with plenty of white space for an elegant feel.
- Subtle transitions and animations to enhance user experience without overwhelming.
